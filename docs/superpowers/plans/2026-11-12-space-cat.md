# Space Cat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Space Cat — a four-lane flying sums game adapted (by permission) from Igor's *Space Cat Math* — as a
fourth Vite entry in alef, with an adaptive sums ladder at 1 mistake in 5, unseen speed adaptation, a parent area,
its voice lines, and a card on the home screen that *one duel* builds.

**Architecture:** A separate Vite entry (`spacecat/index.html` → `src/spacecat/`), in the clock and Book 2 pattern: its
own persisted store, telemetry, parent area and cover. Pure, unit-tested logic in `src/spacecat/logic/` (items and
ladder, prediction on top of `src/shared/adaptive.ts`, wrong answers, speed, the round state machine, the run) feeds an
imperative canvas engine (`src/spacecat/canvas/`, ported from the original) that a React controller hook drives.
Effects and the tune are WebAudio code on Howler's AudioContext; voice lines play through `src/shared/audioCore.ts`.

**Tech Stack:** TypeScript 5.9, React 19, Vite 7, Zustand 5 (persist), Howler 2.2, Canvas 2D, WebAudio, Vitest 4 +
Testing Library (jsdom). Host pipeline for voice: the existing host-local ElevenLabs pipeline of Book 2.

**Spec:** `docs/superpowers/specs/2026-11-12-space-cat-design.md` (read it before any task). Rules:
`docs/minigame-rules.md` (read it before any UI, audio or asset task). Every task's requirements include both.

## Review Focus

1. **The tablet locks or the app changes in the middle of a zoom, a demo, a tip or a voice line:** expect all sound to
   stop, the opaque pause cover, and on return the same sum from the top with no heart lost, the round recorded as cut
   and not tallied, and the demo or tip shown again from its start. Tests: Task 15 `a pause during a zoom restarts the
   same sum and costs no heart`, `a pause during the demo replays the demo`.
2. **Canvas text the DOM scan cannot see:** a stray label, a "?" or a NaN drawn on the canvas. Expect only digits and the
   signs. Tests: Task 13 `drawText records every string`, Task 22 scan of the recorded strings.
3. **Touches at the edges of a round:** a flick and an arrival in the same frame, a tap on a planet during the demo
   line, a drag that ends exactly between two lanes at arrival, a second zoom during a zoom, keys held down. Expect one
   result per round, never a heart for parking between planets. Tests: Task 8 `arrival during a zoom waits for the hit`,
   `between lanes resolves to the nearest lane, ties to the ship's lane`; Task 12 `held key repeats do not skip lanes`.
4. **A save that is missing, old or unreadable, and settings that conflict** (the parent caps the range below the
   open rungs, turns times off after rung 7 opened, fixes the time then goes back to automatic). Expect a fresh save
   from bad JSON, candidates only from rungs that are open and allowed, and the automatic time continuing from its last
   value. Tests: Task 10 `bad JSON gives a fresh save`, Task 5 `turning times off closes rungs 7 to 9 for the choice`.
5. **No sound at all** (voice files not generated yet, AudioContext still suspended, a slow phone): expect the game to
   flow silently and in time; a missing line never blocks the planets. Tests: Task 14 `say resolves at once for an
   unknown id`, Task 15 `a whole level plays with no audio files`.

### Task 3: Facts, items and the ladder (M) — parallel with 6, 7, 9

**Files:** Create `src/spacecat/logic/facts.ts`, `src/spacecat/logic/facts.test.ts`

**Interfaces:**
- Produces:
```ts
export type Op = '+' | '−' | '×' | '÷'
export type Hole = 'c' | 'a' | 'b'            // which place is the ring: a op b = c
export type RungId = 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9
export interface Item { id: string; fact: string; a: number; op: Op; b: number; c: number; hole: Hole; rung: RungId; answer: number }
export const RUNGS: { id: RungId; needs?: 'times' | 'divide' }[]   // 7, 8 need 'times'; 9 needs 'divide'
export function itemsOfRung(r: RungId): Item[]
export function itemById(id: string): Item | undefined
export const isZeroFact: (it: Item) => boolean   // + 0 or − 0 (either operand 0 for +, b = 0 for −)
export function maxNumber(open: RungId[]): number // the highest number in any item of these rungs
```
- Ids: `` `${a}${opAscii}${b}=${c}/${hole}` `` with opAscii `+ - x /`, e.g. `3+4=7/c`, `3+4=7/b`. Fact keys: `+` → `` `+${min(a,b)},${max(a,b)}` `` (so `3+4` and `4+3` are one fact); `−` → `` `-${a},${b}` ``; `×` → sorted like `+`; `÷` → `` `/${a},${b}` ``. Missing-number items share the fact key of their plain item.
- Rung contents (all results ≥ 0; `answer` is the number in the hole):
  1. `+`, `a, b ≥ 0`, `c ≤ 5`, hole `c`.
  2. `+`, `6 ≤ c ≤ 10`, hole `c`.
  3. `−`, `a ≤ 10`, `0 ≤ b ≤ a`, hole `c`.
  4. every item of rungs 1–3 again with hole `a` and with hole `b` (and nothing else).
  5. `+` with `11 ≤ c ≤ 20` and `a % 10 + b % 10 ≤ 9`; `−` with `11 ≤ a ≤ 20`, `1 ≤ b ≤ 9`, `a % 10 ≥ b`. Hole `c`.
  6. `+` with `2 ≤ a, b ≤ 9`, `c ≥ 11`; `−` with `11 ≤ a ≤ 18`, `2 ≤ b ≤ 9`, `a % 10 < b`. Hole `c`.
  7. `×` with one factor in 1–5 and the other in 1–10 (both orders). 8. `×` with factors 1–10 not in rung 7. 9. `÷` from each `×` item of rungs 7–8: `c ÷ a = b`.

- [ ] **Step 1: Write the failing tests:** `rung 1 is the sums to 5` → every item `op '+'`, `c <= 5`, contains `3+2=5/c` and `2+3=5/c` with the same `fact`; `rung 2 holds only 6 to 10` → no item with `c <= 5`; `rung 4 holds only missing-number items of rungs 1 to 3` → every `hole !== 'c'`, every `fact` is a fact of rungs 1–3, count `=== 2 * (itemsOfRung(1).length + itemsOfRung(2).length + itemsOfRung(3).length)`; `rung 5 has no crossing` → contains `12+5=17/c`, `18-3=15/c`, not `8+5=13/c`, not `13-6=7/c`; `rung 6 crosses` → contains `8+5=13/c`, `13-6=7/c`; `no negative numbers anywhere`; `ids are unique and round-trip` → `itemById(it.id) === it` for all; `rungs 7-9 need their switches` → `RUNGS[6].needs === 'times'`, `RUNGS[8].needs === 'divide'`; `maxNumber([1]) === 5`, `maxNumber([1,2,3]) === 10`, `maxNumber([1,2,3,4,5,6]) === 20`.

export interface ItemStats { seen: number; wrong: number; timeout: number; recent: string; times: number[]; picks: Record<string, number> }
export const PRIOR_FIRST = 0.25, PRIOR_NEW_RUNG = 0.3, ZERO_EVERY = 15
