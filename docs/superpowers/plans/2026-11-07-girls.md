# Plan: girls too (spec: ../specs/2026-11-07-girls-design.md)

## Shared

1. `src/shared/player.ts`: the setting in localStorage `alef-player` `{ gender, by, at }`; `getPlayer`, `setGender(g, by)`,
   `useGender()` (useSyncExternalStore, also follows other tabs), `voiceFor(id, gender, hasFile, gendered)` →
   `{ id, fallback }`: the `-f` id for a gendered line when the player is a girl, the masculine id when its file is missing.
   Tests first.
2. `src/shared/GenderQuestion.tsx`: the question screen. Two big wizard pictures (boy, girl), no text. The voice asks once
   (the pictures glow when the voice names them), and again when the child waits 8 s. A tap on a picture chooses; taps
   wait until the question ends (it is an instruction). Each game gives its own pictures, voice player and telemetry.
3. `src/shared/PlayerSetting.tsx`: the parent control (boy / girl / ask again), used in each game's parent area.

## Per game

- Book 2: `LineDef.fe` (one feminine text per variation, `null` = the same for both). The catalog exports `<id>-<n>-f`.
  `sayParts` resolves each id through `voiceFor`. Girl sprites `s-*-girl.webp`; `wizardArt(name, gender)` everywhere a
  wizard is drawn (cover, broom, ghosts, ladder, pause, menu card). Question before the first run when unset.
- Nikkud duel: `DUEL_FEMININE` (line ids with a feminine take), `playLine` resolves through `voiceFor`; cues for `-f`
  files. Girl sprites `wizard-*-girl.webp` (the same pictures as Book 2); `wizardFor(gender)` in the cover, battlefield,
  pause, summary and menu card. The question before the first round; the setting on the progress page.
- Clock: `LineDef.heF`, `CUSTOMER_LINES.he.askF`; captions use the feminine text when it plays. The catalog exports `-f`
  items with a feminine spoken-word map. The question before the welcome; the setting in the parent area.

## Assets (host-local pipelines; the parent reviews)

- Voice: Book 2 (Will), the duel (Will, its own pipeline), the clock (Charlotte and the four Hebrew customers). Every take
  through the automatic checks; a review note per new item.
- Art: 4 girl wizard pictures (broom, cast, dizzy, idle), 2 takes each, the boy sprite as the reference; keyed and cropped
  like the boy; reviewable (OK / reject) on the Book 2 review page.
