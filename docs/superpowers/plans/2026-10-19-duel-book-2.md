# Wizard Duel Book 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build "Book 2" — a letters-and-syllables wizard game with five screens (broom flight, cauldron, ladder, look-alike ghosts, door corridor) and a crystal reward — as a third app in the alef repo, with its generated voice, art and review pipeline.

**Architecture:** A separate Vite entry (`duel2/index.html` → `src/duel2/`), deployed with alef at `/alef/duel2/`, following the clock game's layout (its own persisted store, telemetry, parent area, preload, cover). This replaces the spec's "route next to the duel" default: the clock is the newest pattern and already has the parent area, preload and cover the spec asks for. Pure, unit-tested logic (content, prediction and stages, round generators, run cycle) feeds React screens driven by one controller hook. `src/shared/` (predictor, telemetry, audio core) is reused. Assets are generated host-locally and synced into `src/duel2/assets/`.

**Tech Stack:** TypeScript 5.9, React 19, Vite 7, Zustand 5 (persist), Framer Motion 12, Howler 2.2, Vitest 4 + Testing Library (jsdom). Host pipeline: Python 3.8 stdlib, ElevenLabs API, Gemini API (copied from the clock pipeline).

**Spec:** `docs/superpowers/specs/2026-10-19-duel-book-2-design.md` (read it before any task). Rules: `docs/minigame-rules.md` (read it before any UI, audio or art task).

## Review Focus

1. **Two same-sound items in one hearing choice** (target תָּ with טָ on a broom wave, ghost sign or plate): expect never. Test in Task 4 (`no hearing choice holds two items with the same sound`, exhaustive over all targets and stages).
2. **The run ends inside a screen / the tablet locks mid-flight**: expect the summary at 0 hearts, the next run to start at the following screen, and after a lock the same round to continue with waves restarted from the right edge, never a double answer. Tests in Task 5 (`next run starts after the screen where the last ended`) and Task 12 (`hidden page pauses the flight and resume restarts the wave`).
3. **Missing assets** (no voice file, no image yet — the normal state while generation runs): expect the game to flow silently with fallback drawings. Tests in Task 8 (`say resolves for an unknown id`) and Task 12 (`a full cycle completes with no audio files`).
4. **Font not loaded or `measureText` missing** (jsdom, slow phone): expect glyphs drawn centered by the line box and re-centered once the font loads, never a crash. Test in Task 9 (`falls back to line-box centering without a measurer`).
5. **Taps at the wrong time** (during an instruction, a second tap during feedback, a drag that ends between lanes, a double tap on a key): expect them ignored, one answer per round. Tests in Task 11 (`drag released between lanes snaps to the nearest lane`) and Task 12 (`taps during the question line are ignored`, `second tap during feedback is ignored`).
